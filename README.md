## 🚀 What I'm Building

### 🟦 SwipeNet
A swipe-based **job & internship marketplace**.

Students discover opportunities by swiping job cards:

**Swipe Right → Apply**

Employers discover applicants by swiping candidate cards:

**Swipe Right → Shortlist**

The platform connects both sides through applications, hiring workflows, notifications and messaging.

**Stack:** React • Node.js • Express • MongoDB • Socket.io
